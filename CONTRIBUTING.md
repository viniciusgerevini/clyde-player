# Contributor guidelines

This document summarizes the main points for people interested in contributing to this project.

## Reporting bugs

If you found a bug, please report as an issue in this repository. To help streamline the process, please include the version of the player you are using and your operational system.

## Feature requests

For feature requests, open an issue in this repository explaining the new feature and at least one use-case for it.

## Code contributions and pull requests

Even though I'm happy to accept impromptu pull requests, it's better to open an issue first to discuss the contribution to avoid wasting time. Minor bugs and small improvements are usually straight forward, but for significant changes we need to make sure that:

- The feature solves a common problem or enhance the player experience. Avoid features that are too niche or that there are simple workarounds.
- We have a chance to discuss architectural changes to ensure code quality and alignment with the project's direction.

### PR etiquette

- Make sure your changes are covered by automated tests for the relevant changes.
- Include a description of the problem being solved, a link to the issue if it exists, and any details you think might help with the review, like use-cases, usage instructions, and alternative approaches considered.
